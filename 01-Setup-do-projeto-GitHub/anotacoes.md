Nessa aula irei aprender a como estruturar meus projetos utilizando IA, também controlar meu código usando git e subir para o repositório remoto no github.
Com isso irei economizar horas de código.

Link do repositório no github: https://github.com/MellonFive/ecommerce-syntaxwear

*Só tome cuidado quando fazer git clone em uma pasta que já está versionada.*

Dando um git clone, é mais fácil e mais rápido para produzir. Não preciso linkar o git para o github usando git remote origin main. 
Então sempre que começo um projeto novo, crio o repositório primeiro e uso o git clone depois no meu computador. Porque git clone já faz a ligação da pasta local com a pasta remoto.
